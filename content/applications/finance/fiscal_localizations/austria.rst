=======
Austria
=======

Configuration
=============

:ref:`Install <general/install>` the following modules to get all the features of the Austrian
localization.

.. list-table::
   :header-rows: 1

   * - Name
     - Technical name
     - Description
   * - :guilabel:`Austria - Accounting`
     - `l10n_at`
     - Default :ref:`fiscal localization package <fiscal_localizations/packages>`.

.. note::
   The Austrian localized financial reports (balance sheet according to § 224 UGB, profit and loss
   according to § 231 UGB) and the Austrian SAF-T export are **not** available in this edition. Use
   the generic :doc:`financial reports <../accounting/reporting>` instead.
